# Dengeli Duyum

Dengeli Duyum Odyoloji Kliniği Yönetim Paneli ve Randevu Sistemi.

## Özellikler
- **Hasta Randevu Sistemi:** Hastalar kayıt olup randevu alabilir, geçmiş randevularını görebilir.
- **Doktor Paneli:** Doktorlar randevuları görebilir, anamnez formlarını dinamik sorularla doldurabilir.
- **Admin Paneli:** Klinik yönetimi, doktor atamaları ve sistem ayarları.
- **Dinamik Form Altyapısı:** Odyolojik ve vestibüler muayenelere özel sorular.

## Kurulum
```bash
npm install
npm run dev
```

## Teknolojiler
- Next.js 16 (Turbopack)
- NextAuth.js
- Drizzle ORM
- Turso (SQLite)
